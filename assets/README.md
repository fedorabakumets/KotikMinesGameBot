# Логотип «Мин»

Создан встроенным imagegen в режиме генерации нового изображения. `mines-logo.png` — исходный логотип; `mines-avatar.jpg` — то же изображение в формате JPG для Telegram. Преобразование формата не меняет композицию.

## Точный промпт

```text
Use case: logo-brand. Generate a polished square Telegram avatar logo for a casual Mines puzzle game bot. One bold central emblem combining a charming round dark mine with a short fuse and a bright faceted cyan crystal, clearly communicating mines and collecting gems. Premium playful game identity, smooth chunky illustrated shapes, restrained luminous accents, strong simple silhouette, deep midnight background, generous safe padding for a circular crop, excellent readability at tiny avatar sizes. Finished raster brand mark, no text, no letters, no coins, no money symbols, no casino imagery, no interface mockup, no border, no watermark.
```
